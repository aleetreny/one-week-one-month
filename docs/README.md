# AI Speeds the Work, Not the Wait — the scrolling version

Static site served by GitHub Pages from `/docs`: https://aleetreny.github.io/one-week-one-month/

One canvas of 6,666 points, one per research task in SciNet, rearranged by scroll into the paper's figures.
`data.json` is built by `web/build_data.py`. Data: SciNet (Alamos & Althoff 2026), CC BY 4.0.
The paper is in `paper/` and the code that reproduces its numbers in `replication/`.
